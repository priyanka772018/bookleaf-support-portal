# Example: the exact draft prompt for a real ticket

Generated by `buildDraftUserMessage()` for seeded ticket **BL-00001** (Ananya Reddy, *Between Two Temples*, never paid), as of 2026-10-21. This is the full **user** message — the static system prompt (persona, tone guidelines, writing rules) is in [`server/src/ai/prompts/draft.js`](../server/src/ai/prompts/draft.js).

Note what is *not* here: the Printing, ISBN, Distribution and Production policies, the other categories' examples, and — for authors with several titles — their other books. Note also that every date and amount (next payout deadline, the OVERDUE flag) was computed in code, so the model only has to communicate it.
